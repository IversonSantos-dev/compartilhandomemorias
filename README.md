# Compartilhando Memorias

A web app for instant photo sharing and collaborative galleries.

Users can create and share photo galleries, with secure login for owners and public upload via QR code or unique links. Features include real-time gallery updates, individual file upload progress, and filters for easy browsing.

This project was built with [Lovable](https://lovable.dev).
